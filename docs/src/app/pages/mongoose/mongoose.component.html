Best Practices

Use compound indexes

Always include tenantId in indexes for multi-tenant queries.

Aggregate with $match first

Filter by tenantId early in aggregation pipelines.

Filter populations

Add tenant match conditions when populating references.

Consider sharding

For large multi-tenant deployments, shard by tenantId.
