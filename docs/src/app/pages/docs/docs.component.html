Options Reference

Option Type Default Description
extractionStrategy 'header' | 'subdomain' | 'path' | 'query' | 'custom' 'header' Strategy for extracting tenant ID
tenantHeader string 'x-tenant-id' Header name for header strategy
tenantQueryParam string 'tenantId' Query parameter for query strategy
tenantPathIndex number 0 Path segment index for path strategy
customExtractor (req) => string | null | Promise - Custom extraction function
tenantResolver (id) => Tenant | null | Promise - Resolve full tenant from ID
requireTenant boolean false Throw if tenant not found
excludeRoutes (string | RegExp)[] [] Routes to skip tenant extraction

Header Strategy

Extract tenant ID from a request header. This is the default and most common strategy.

Usage

Subdomain Strategy

Extract tenant ID from the subdomain of the request URL.

💡
Example: tenant-123.example.com → tenant ID: "tenant-123"

Path Strategy

Extract tenant ID from a URL path segment.

💡

/tenant-123/api/users → tenant ID: "tenant-123"

/api/tenant-123/users → tenant ID: "tenant-123" (with tenantPathIndex: 1)

Query Strategy

Extract tenant ID from a query parameter.

💡
Example: /api/users?tenantId=tenant-123 → tenant ID: "tenant-123"

Custom Strategy

Implement your own extraction logic for complex scenarios.

Decorators

@CurrentTenant()

Inject the full tenant object into a controller method.

@TenantId()

Inject only the tenant ID.

@RequireTenant()

Mark a controller or method as requiring a valid tenant context.
