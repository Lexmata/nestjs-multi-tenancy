TypeORM Multi-Tenancy

Build multi-tenant applications using TypeORM with a reusable base repository pattern that automatically scopes all database operations to the current tenant.

🏗️ Base Repository 🔍 QueryBuilder 📡 Subscribers
1

Define Your Entities

Create TypeORM entities with proper tenant relationships. Add tenantId to every tenant-scoped entity with indexes for performance.

2

Create the Base Repository

Create an abstract base repository that automatically scopes all queries to the current tenant. This pattern provides DRY, type-safe multi-tenancy across all your repositories.

3

Extend the Base Repository

Create entity-specific repositories by extending the base. Add custom query methods as needed.

4

Create Your Service

Services use the repository without worrying about tenant scoping—it's handled automatically.

5

Configure Modules

Set up the database module, app module with multi-tenant configuration, and feature modules.

Alternative: QueryBuilder Approach

For complex queries, you can use TypeORM's QueryBuilder with a helper method that pre-scopes queries to the current tenant.

Bonus: TypeORM Subscriber for Audit

Use a TypeORM subscriber to automatically set tenantId on insert and validate tenant access on updates.

Key Benefits

🏗️

DRY Base Repository

Write tenant scoping logic once, reuse across all entity repositories.

🔒

Automatic Scoping

Every query is automatically filtered by tenant. No manual filtering needed.

📝

Type Safety

Full TypeScript support with generics in the base repository.

🔍

QueryBuilder Support

Complex queries via QueryBuilder with tenant scope helpers.
